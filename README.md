Biochemistry Data Analysis Project

Project Overview
This project demonstrates the use of Microsoft Excel to analyse biochemical experimental data, investigate enzyme activity under different pH and temperature conditions, and determine protein concentrations using the Bradford assay.

Project Objectives
- Analyse the effect of pH on amylase activity.
- Investigate the effect of temperature on enzyme activity.
- Determine protein concentrations using the Bradford assay.
- Organise, analyse, and interpret experimental datasets.

Workbook Contents
1. README: Project overview and skills demonstrated.
2. Enzyme vs pH: Analysis of amylase activity across pH 4.0–9.0, identifying an optimum pH of 7.0.
3. Bradford Assay: BSA standard curve and protein concentration calculations for liver, serum, muscle, and plant samples.
4. Temperature Effect: Analysis of enzyme activity between 20°C and 60°C, identifying an optimum temperature of 37°C.

Tools and Skills
- Microsoft Excel
- Data cleaning and organisation
- Quantitative data analysis
- Protein concentration calculations
- Standard curve analysis
- Data visualisation
- Scientific interpretation and reporting

Key Findings
- Optimum amylase pH: 7.0.
- Optimum enzyme temperature: 37°C.
- Protein concentrations estimated using the Bradford assay.

Note on Data
The numerical datasets are simulated educational examples created to demonstrate biochemical data analysis techniques. They are not actual laboratory measurements.
